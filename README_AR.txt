GalaxyClock Font Studio — نسخة تعديل خطوط فعلية

التشغيل على كمبيوتر:
1) ثبّت Python 3.10 أو أحدث.
2) افتح Terminal / CMD داخل مجلد المشروع.
3) نفّذ: pip install -r requirements.txt
4) شغّل: python app.py
5) افتح: http://127.0.0.1:5000

ارفع ملف TTF، واضبط الارتفاع والعرض والسُمك والميل، ثم اضغط «تعديل الخط وتنزيل TTF».

ملاحظات:
- تعديل الحدود الحقيقي يدعم خطوط TrueType التي تحتوي جدول glyf (غالبًا TTF).
- ملفات OTF المبنية على CFF قد تُرفض برسالة توضح عدم دعمها في هذه النسخة.
- الواجهة تعرض معاينة تقريبية عبر CSS؛ ملف TTF الناتج يُعدّل هندسيًا في outlines.
- يُفضّل الاحتفاظ بنسخة احتياطية من الخط الأصلي. بعض الخطوط المعقدة أو المركّبة قد تحتاج معالجة إضافية.
- الاستخدام على أندرويد مباشرة يحتاج بيئة Python مناسبة أو استضافة للخادم؛ فتح index.html وحده لا يتيح تصدير TTF المعدّل.
